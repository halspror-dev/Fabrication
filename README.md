# fabrication (private)

Code for carlie's metal products, starting with the all-metal spray can trigger handle.

- `drawing-scripts/`: generate the 1:1 template PDFs and 3D views (see its README).
- `laser-order/v1-v0.3/`: scripts that made and checked the v1 laser-cut DXFs.
- `tools/setup_graphify.sh`: builds a local code map (code-only, nothing uploaded).

Keep this repo private until a provisional patent is filed.
